# FilmGlass 2.0 — личный кинотеатр

**Готовый статический сайт для GitHub Pages.** Без регистрации, внешних библиотек и отправки видео на сервер. Код доступен публично, но загружаемые пользователем видео и заметки хранятся в IndexedDB *конкретного браузера*.

## Публикация через GitHub Pages

В репозитории уже загружены сайт и автоматический workflow `.github/workflows/pages.yml`. Для первой публикации нужно один раз включить GitHub Pages:

1. Перейдите в **Settings → Pages** репозитория.
2. В блоке **Build and deployment** в поле **Source** выберите **GitHub Actions**.
3. После этого откройте **Actions → Publish FilmGlass to GitHub Pages → Re-run jobs** (если первоначальная попытка завершилась ошибкой). При следующих изменениях в `main` сайт будет публиковаться автоматически.

Адрес после успешного деплоя: `https://nervanadio-cell.github.io/FilmGlass/`. Факт включения Pages и успешный статус Actions необходимо проверить, прежде чем считать сайт опубликованным.

### Как пользоваться

Откройте сайт, нажмите **Добавить**, выберите видео/аудио с устройства. Они сохранятся в локальном IndexedDB. Библиотека, метки и место остановки сохраняются при повторном открытии в том же браузере на том же URL. В плеере **Играть во время просмотра** включает пузырьки, песок или 2048. Отдельно доступны субтитры SRT/VTT и таймер сна.

### Без интернета

В `sw.js` включено кеширование оболочки сайта для повторных посещений. Для первого открытия нужен интернет. После первого успешного открытия и установки service worker интерфейс сайта может открываться офлайн; загруженные видео остаются на устройстве в IndexedDB. Офлайн-доступ зависит от политики браузера и сохранности кеша. Проверяйте после отключения сети.

### Важно

- GitHub **не получает видео**, загруженное в приложении. GitHub хранит только HTML, CSS, JS, PWA-иконки и этот README.
- Данные на другом устройстве/браузере не появятся. Домен GitHub Pages и открытие локального `file://` используют разное хранилище.
- Очистка данных сайтов или автоматическая очистка браузером может стереть видео. Храните оригиналы отдельно.
- Доступное место ограничено квотой браузера, поддержка видео зависит от кодеков (лучше MP4/H.264/AAC или WebM).
- Для локального запуска на ПК можно выполнить `python -m http.server 8080` в папке проекта и открыть `http://localhost:8080`. При обычном `file://` кеширование PWA недоступно.
- Субтитры SRT/VTT, добавленные в плеере, действуют в рамках текущего просмотра.
